# Contributing to Cradle

Thanks for your interest in Cradle!

## Current status: not accepting external contributions

The Cradle is in early development and is currently maintained as a personal project. At this stage, **we are not accepting external pull requests**. Please do not open PRs — they will be closed without review.

This isn't a reflection on the quality of any contribution; the project's direction, scope, and internal conventions are still in flux, and accepting outside code would make that harder to iterate on.

## What you _can_ do

- **Report bugs** — open a [GitHub Issue](https://github.com/coryrylan/Cradle/issues) with:
  - Version (`Cradle --version`) and platform (OS, arch)
  - The command you ran and the output you got
  - What you expected instead
- **Suggest features or checks** — issues are welcome. A clear use case is more useful than a proposed implementation.
- **Ask questions** — open a [GitHub Discussion](https://github.com/coryrylan/Cradle/discussions) if you're unsure whether something is a bug, a feature request, or intended behavior.
- **Report security issues privately** — see [SECURITY.md](SECURITY.md). Do not open public issues for vulnerabilities.

## When this will change

The plan is to open the project to external contributions once:

- The check API and scoring model have stabilized
- There's a documented process for proposing and reviewing new checks
- CI and release automation are ready to handle outside PRs

When that happens, this file will be updated with contribution guidelines, coding standards, and the PR workflow. Watch the repo or star it to be notified of releases.

Thanks for understanding.
